## Already landed (do not rewrite — verify only via tsc)

- `packages/fret/src/rpc/outcome.ts` — `RpcOutcome<T>` discriminated union, all 8 variants
  (`ok` / `skipped` / `cancelled` / `timeout` / `unreachable` / `foreign-protocol` /
  `decode-error` / `busy`), per-variant doc comments stating what each proves about the peer.
- `packages/fret/src/rpc/request.ts` — `rpcRequest<T = undefined>` + `RpcRequestOptions<T>`,
  per the settled plan:
  - Caller bugs (`peerIdFromString`, `if-addressed` without `isDialable`) throw before
    `deadline()` is armed; network outcomes never throw.
  - One shared `classify` (caller-signal → `cancelled`; `isUnsupportedProtocolError` →
    `foreign-protocol`; `isFrameTruncationError` / `payload too large` → `decode-error`;
    deadline aborted or `DeadlineExpiredError` name → `timeout`; else `unreachable`) used by
    open, write and read phases — one classifier because `negotiateFully: false` defers
    negotiate failures to the first read.
  - Decode phase separate from `classify`: busy-shape test on parsed value before
    `opts.decode`; decode throws → `cancelled` (caller aborted) or `decode-error`; double
    parse accepted and commented.
  - Backpressure honored: `sendFramed` boolean `false` → `awaitDrain` loop
    (re-checks `writableNeedsDrain` after each `'drain'`; both listeners removed in both arms;
    guarded so plain test stubs without the surface skip it), bounded by the deadline signal.
  - Dial mapping: `'never'` → `requireExisting: true`; `'if-addressed'` →
    `isDialable(peer) ? default : requireExisting: true`; existing connection always usable;
    `undefined` stream → `skipped`. Documented at site.
  - Single clock: `readFramed(stream, maxBytes, Infinity, { signal: d.signal })`.
  - RTT from after open (`Math.max(0, Date.now() - start)`); write-only path returns
    `ok` with `value: undefined`, rtt still measured.
  - `finally { await releaseRpcStream(stream, d.signal); d.cancel(); }` — release before
    cancel, ordering comment in place.
  - `maxBytes` default 64 KiB (`DEFAULT_MAX_BYTES`), doc-commented.
  - `BusyResponseV1` imported type-only from `../index.js` (ping.ts precedent — no runtime
    cycle).
