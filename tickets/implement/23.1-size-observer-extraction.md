## What is being extracted

One contiguous block of `packages/fret/src/service/fret-service.ts` with **zero coupling** to the
Digitree store or to libp2p — it reads nothing but its own observation array and the clock:

| Member | Approx. line | Role |
|---|---|---|
| `networkObservations` | 390 | the observation array (estimate, confidence, timestamp, source) |
| `maxObservations = 100` | 396 | count bound |
| `observationWindowMs = 300000` | 397 | 5-minute sliding window |
| `reportNetworkSize` | 2879 | append, trim by age, trim by count |

| `getNetworkChurn` | 2967 | rate of change per minute, recent half vs older half |
| `detectPartition` | 2994 | sudden-drop and churn-threshold detection |

Its only outward dependency is the *local* FRET estimate, which `getNetworkSizeEstimate` currently
computes inline by calling `estimateSizeAndConfidence(this.store, ...)` and then prepending as a
`source: 'fret'` observation. That one call is the whole coupling, and passing the result **in**
rather than reaching **out** is what makes the class store-free.

## The interface

New module `packages/fret/src/service/size-observer.ts`.

```ts
/** One reported network-size observation, local or peer-supplied. */
export interface SizeObservation {
	estimate: number;
	confidence: number;
	timestamp: number;
	/** Provenance for diagnostics only; nothing branches on it. */
	source: string;
}

/** The blended answer, byte-identical in shape to today's `getNetworkSizeEstimate` return. */
export interface BlendedSize {
	size_estimate: number;
	confidence: number;
	/** Observations contributing, not distinct observers. */
	sources: number;
}

/** The caller's own locally-derived estimate, supplied per call. */
export interface LocalSizeEstimate {
	n: number;
	confidence: number;
}

export interface SizeObserverOptions {
	/** Sliding window; observations older than this are dropped. Default 300_000. */
	windowMs?: number;
	/** Hard count bound; the newest are kept. Default 100. */
	maxObservations?: number;
	/** Clock seam. Default `Date.now`. Injectable so decay and blend are testable without sleeps. */
	now?: () => number;
}

export class SizeObserver {
	constructor(opts?: SizeObserverOptions);
	/** Record an external observation, then trim by age and by count. */
	report(estimate: number, confidence: number, source?: string): void;
	/** Blend `local` with the recorded observations. `local` is always the first observation. */
	blend(local: LocalSizeEstimate): BlendedSize;
	/** Rate of change per minute across the window's recent vs older half. 0 when undecidable. */
	churnPerMinute(): number;
	/** Sudden-drop / high-churn heuristic. Needs `local` because it consults the blended size. */
	detectPartition(local: LocalSizeEstimate): boolean;
	/** Defensive copy, for diagnostics and tests. */
	observations(): SizeObservation[];
	/** Drop every observation — a start -> stop -> start cycle is a fresh run. */
	clear(): void;
}
```

`FretService` keeps a `private readonly sizeObserver = new SizeObserver()` and its four public
methods become one-line delegations, computing the local estimate where `getNetworkSizeEstimate`
does today:

```ts
private localSizeEstimate(): LocalSizeEstimate {

		filter: isLiveMember,
		selfCoord: this.cachedSelfCoord ?? undefined
	});
	return { n: e.n, confidence: e.confidence };
}
```

The `FretService` public interface in `src/index.ts` and the `Libp2pFretService` pass-throughs
(`src/service/libp2p-fret-service.ts:195-209`) are **unchanged** — this is an internal move.

## Behavior parity, and the one deliberate change

Carry the maths across verbatim. Three details currently encoded in comments at the site must
survive, and the new unit spec is where they get pinned properly for the first time:

- **Two different denominators in `blend`.** `size_estimate` is weighted by recency x confidence;
  the reported confidence is weighted by recency **only**. Dividing a recency-weighted numerator
  by an unweighted observation count is what previously made four agreeing observations at
  confidence 0.5 report 0.23. Pin both denominators independently.
- **The local estimate is always the first observation**, so the observation list is never empty.
  The reachable degenerate case is every observation carrying confidence 0, guarded by
  `totalWeight === 0 || recencySum === 0` returning `{0, 0, 0}`.
- **`detectPartition` gates on `observations.length < 10`, on blended confidence `< 0.3`, and on
  fewer than 3 observations older than 30 s** before it can return true. The `oldAvg` divisor is
  `Math.min(5, oldObs.length)` over `oldObs.slice(-5)` — carry that arithmetic exactly, including
  its quirk that `slice(-5)` and the divisor can disagree when `oldObs.length` is between 3 and 5.
  Preserve it; do not "fix" it in this ticket. If it is wrong, that is a separate finding with its
  own evidence.

The one deliberate change: **`stop()` calls `sizeObserver.clear()`.** Today `networkObservations`
survives a stop -> start cycle, which is the same mistake as carrying `negotiateFailures` across a
restart (`docs/fret.md`, *Security and abuse considerations*, already states that rule for the
backoff and departure-debounce maps). Note it in `docs/fret.md` under *Network size estimation*.

## Edge cases & interactions

- **Empty observation list.** `blend` is called with only the local estimate; `churnPerMinute`
  returns 0 (`< 2` observations); `detectPartition` returns false (`< 10`).
- **Every observation at confidence 0.** `totalWeight` and `recencySum` both reachable at 0 —
  returns `{size_estimate: 0, confidence: 0, sources: 0}`. Pin this; it is the guarded degenerate
  case named in the current comment.
- **All observations older than the window.** `report` trims on append, so the array can only hold
  stale entries if nothing has been reported since. `blend` must still weight them (their recency
  weight is tiny, not zero) rather than divide by zero.
- **Count bound vs age bound interacting.** More than `maxObservations` inside the window: the
  newest `maxObservations` survive (`slice(-max)`). Assert the oldest are the ones dropped.
- **Clock going backwards / identical timestamps.** With an injected `now` that does not advance,
  every observation has age 0 and recency weight 1. Must not divide by zero and must not report
  confidence > 1 (`Math.min(1, avgConfidence)` is the guard).
- **`churnPerMinute` with everything on one side of the half-window.** All-recent or all-older
  returns 0. Pin both.
- **`detectPartition` boundary at exactly 10 observations and exactly confidence 0.3** — the
  comparisons are `< 10` and `< 0.3`, so 10 and 0.3 proceed.
- **Negative or non-finite reported values.** `reportNetworkSize` is public
  (`src/index.ts:116`) and `calibrateSizeFromSnapshot` feeds it wire-derived numbers; it currently
  gates on `size_estimate > 0 && confidence > 0` at the *caller*. Assert the observer does not
  produce `NaN` from a `NaN` input reaching it directly — either reject non-finite input at
  `report` or pin today's behavior explicitly. Prefer rejecting at `report`: the class is now the
  boundary, and a `NaN` in the array poisons every subsequent blend.
- **`clear()` mid-flight.** `stop()` may run while a stabilization tick is between its awaits;
  `blend` after `clear` must return the local estimate alone, not throw.
- **Diagnostics.** Check `getDiagnostics` (~1161 calls `getNetworkSizeEstimate`) still reports the
  same shape after the move.
