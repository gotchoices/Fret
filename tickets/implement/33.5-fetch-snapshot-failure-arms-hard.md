## Arm 3: `timeout`

a **short** `MAINTENANCE_SNAPSHOT_TIMEOUT_MS` so the test doesn't wait out the real 1000ms default.

  stream's blocking behavior, or whether it's simpler to write a 3-line local version:

  internal deadline (not an external abort) is what should end this test — verify which fits
  better once you see how `rpcRequest`'s read-with-`Infinity`-timeoutMs mode actually gets bounded

  `fetchAndMergeSnapshot` — passing `undefined` there is fine, the internal deadline still fires on
