## Non-mutating teardown
`test/helpers/libp2p.ts:63-67`:
```ts
export async function stopAll(nodes: any[]): Promise<void> {
	for (const n of nodes.reverse()) {
		try { await n.stop() } catch {}
	}
}
```
`.reverse()` mutates the caller's array in place. Any caller that reuses the list after calling
`stopAll` gets it silently reversed. Make it non-mutating (`[...nodes].reverse()` or iterate
backwards by index without reversing).
