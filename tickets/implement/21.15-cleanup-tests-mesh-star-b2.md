## The helper (already landed, do not redo)

`packages/fret/test/helpers/mesh.ts` exists, type-checks, and is proven end-to-end by
`test/route.maybeact.integration.spec.ts`, which was migrated onto it and passes. Read that spec
first — it is the worked example. Surface:

```ts
export type Topology = 'star' | 'line' | 'full'
export async function buildMesh(count: number, opts?: { factory?: NodeFactory }): Promise<Mesh>

interface Mesh {
	readonly nodes: Libp2p[]
	readonly ids: string[]            // nodes[i].peerId.toString(), precomputed
	readonly services: FretService[]  // empty until addServices()
	connect(topology: Topology): Promise<void>
	addServices(cfg: Partial<FretConfig> | ((i: number, mesh: Mesh) => Partial<FretConfig>)): Promise<void>
	stop(opts?: { skip?: number[] }): Promise<void>
}
```

`connect` and `addServices` are separate, caller-ordered calls on purpose: dialing before
constructing services means `start()`'s `seedFromPeerStore` already sees the connections; dialing
after means the ring is discovered through `peer:connect`. **Both rigs here are services-first,
then star** — and one of them says so in a comment. Preserve the order and keep the comment.

`mesh.stop()` stops services newest-first, each in its own `try/catch`, then `stopAll(nodes)`.
`mesh.stop({ skip: [i] })` leaves both the service and the node at index `i` alone — that is the
replacement for the "null the array slot so `afterEach` skips it" trick below.

## The shared reshaping problem

Both files hold module-level `let nodes: Libp2p[]` / `let services: CoreFretService[]`, reassign
them at the top of each test from the local `makeMesh` return, and tear down in one `afterEach`
that does per-service `try { await s.stop() } catch {}` then `stopAll(nodes.filter(Boolean))`.
The `filter(Boolean)` exists only because one test nulls array slots (see below).

The shape that maps onto the helper — apply to both files:

```ts
let mesh: Mesh | undefined
/** Indices a test stopped itself mid-case; afterEach must not double-stop them. */
let alreadyStopped: number[] = []

afterEach(async () => {
	await mesh?.stop({ skip: alreadyStopped })
	mesh = undefined
	alreadyStopped = []
})
```

Each test then does `mesh = await makeMesh(n)` and `const { nodes, services } = mesh` locally, so
the test bodies below the first two lines are unchanged. Resetting `alreadyStopped` in `afterEach`
(not in the test) is what keeps it correct when a test throws before reaching its own cleanup.
