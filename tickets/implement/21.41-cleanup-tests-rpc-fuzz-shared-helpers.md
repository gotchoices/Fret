## Why this is its own step

`packages/fret/test/rpc.handler-fuzz.spec.ts` is 2115 lines holding three tiers of tests. Two of
those tiers are moving out into their own files. Both moved tiers and the tier that stays use the
same small fixtures at the top of the file, so the fixtures have to live somewhere all three can
import from *before* the move, or the move turns into "relocate a block and hand-copy its
fixtures" — which is how three copies of one rule drift apart.

Doing it as a separate step also means the move that follows is provably a pure move: this ticket
changes no test, adds no test, and deletes no test.

## Design

Create `packages/fret/test/helpers/rpc-fuzz.ts`, beside the existing `test/helpers/libp2p.ts` and
`test/helpers/maintenance-rig.ts`. It exports exactly the names in the table above (plus anything
the confirming greps show also crosses), with their existing doc comments carried over verbatim —
those comments explain *why* each fixture is shaped the way it is and are the reason the fixtures
are worth sharing rather than copying.

`rpc.handler-fuzz.spec.ts` then imports them from there and keeps everything else exactly as it is.

Do not refactor a fixture while moving it. If one looks wrong, say so in the review handoff; do not
fix it here, or the "pure move" property of the next ticket is gone before it starts.

## Edge cases & interactions

- The helper file is `test/helpers/rpc-fuzz.ts` — **not** a `.spec.ts` file. `packages/fret`'s test
  script globs `test/**/*.spec.ts`, so a helper named `*.spec.ts` would be run as an empty suite.
- `test/helpers/*.ts` files are type-checked by `npx tsc --noEmit` from `packages/fret` like any
  other test file, so a stranded or mistyped export fails there.
- The `unhandledRejection` guard on the top-level `describe` (lines 249–259) is untouched by this
  ticket. It gets copied into the new files by the *next* ticket.
- Count `it(` occurrences in `rpc.handler-fuzz.spec.ts` before and after; the numbers must match
  exactly, since this ticket moves no test.
