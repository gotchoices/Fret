## Root cause (for context — already fixed, no need to re-derive)

`uniformCoord` divided by `this.nextPeerIndex`, which `handleJoin()` increments *before* placing
(`const index = this.nextPeerIndex++`) — so each joiner's coordinate divided by its own
post-increment index instead of the population it should spread across, landing at fraction
`index / (index + 1)` of the ring and packing tighter as the run went on. `initialize()` was
unaffected since `nextPeerIndex` was fixed at `config.n` there. Fix: joiners now get a seeded
random coordinate (`randomCoord()`) instead of index arithmetic; initial population keeps uniform
spacing over the fixed `config.n`.
