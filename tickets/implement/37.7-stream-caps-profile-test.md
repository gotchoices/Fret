## What already landed (do not re-derive)

- `FretService.streamCaps()` — private, `packages/fret/src/service/fret-service.ts:2087`,
  immediately after `mergeSnapshotCaps()`. Returns `{ maxInboundStreams: 128, maxOutboundStreams: 256 }`
  for the `core` profile and `{ maxInboundStreams: 32, maxOutboundStreams: 64 }` otherwise.
  Hard-coded literals, no config knob.
- `registerRpcHandlers()` — `fret-service.ts:1273` — computes `const streamCaps = this.streamCaps()`
  at its top and passes it as the **last** argument to all four registrar calls
  (`registerNeighbors` ~1281, `registerMaybeAct` ~1301, `registerLeave` ~1316, `registerPing` ~1325).
  It is on the `start()` path, so a start→stop→start cycle re-applies it.
- Each registrar takes one optional trailing `streamCaps: StreamCaps = {}` and forwards it verbatim:
  `registerNeighbors` (`src/rpc/neighbors.ts:47`) into **both** protocols it registers — the
  reply-only `PROTOCOL_NEIGHBORS` and, under `if (onAnnounce)`, `PROTOCOL_NEIGHBORS_ANNOUNCE` —
  plus `registerLeave` (`leave.ts:29`), `registerPing` (`ping.ts:32`), `registerMaybeAct`
  (`maybe-act.ts:27`).
- The five protocol ids come from `makeProtocols(networkName)` in `src/rpc/protocols.ts`:
  `${prefix}/neighbors`, `${prefix}/neighbors/announce`, `${prefix}/maybeAct`, `${prefix}/leave`,
  `${prefix}/ping`, where `prefix = /optimystic/${networkName}/fret/1.0.0`.

## The test to write

A cheap spy on `node.handle` asserting the service passes Core 128/256 and Edge 32/64 through for
**all five** protocols — in the spirit of the acceptance-cap specs in
`test/rpc.snapshot-merge-cap.spec.ts`, which count real calls rather than inferring a bound from the
absence of a crash. This is what actually pins the profile split.

It must also cover the **start→stop→start** case: `stop()` unhandles all five protocols and
`start()` re-registers them, so assert the caps are still applied after a full cycle rather than
assuming it.

Note the announce protocol is only registered when `onAnnounce` is supplied — `FretService` always
supplies it, so all five should appear, but a spy asserting "five distinct protocols" will catch it
if that ever changes.
