## Design (resolved)
The natural seams are already visible in the code:
- **Placement** — `generateCoord` and its strategies, `bigintToCoord`/`toCoord` usage.
- **Reachability model** — `partition`/`heal`/`reachable`/`contactAllowed`.
- **Liveness model** — `contactSweep`/`reprobeDeadEntries`.
- **Measurement** — `snapshotCoverage`/`deadNeighborRatio`.
- Whatever remains (event scheduling/dispatch, the stabilization tick, routing) stays as the core
  `FretSimulation` class, composing the extracted pieces.

Extract each seam into its own module under `test/simulation/`, imported by `fret-sim.ts`. Keep
`FretSimulation`'s public API (whatever `test/simulation.spec.ts`, `test/simulation.partition.spec.ts`,
`test/simulation.routing.spec.ts` and any other consumers call today) unchanged — this is
prevention/hygiene, not a behavior change, so no test outside this file's own consumers should
need to change.

## Edge cases & interactions
- This is refactor-only: every simulation spec (`test/simulation*.spec.ts`) must pass
  byte-for-byte identically before and after — same pass/fail outcomes, same deterministic
  results (the RNG seeding must be untouched by the split).
- The partition/reachability model and the liveness model interact (a partitioned peer's contact
  failures still flow through `contactSweep`) — make sure extracting them into separate modules
  doesn't accidentally break the shared state they both read/write (e.g. peer state records).
  Prefer passing state explicitly between modules over each module holding its own hidden copy.
- Watch for the two now-stale `24-sim-router-realism` comments this ticket's sequencing-context
  section above already explains are resolved — if any reference survives in code comments
  (`contactSweep`'s doc comment, or near the routing candidate-filter), reword them to point at
  the actual landed work rather than the removed placeholder name, don't just delete them blind.
- Confirm no consumer outside `test/simulation/` reaches into `fret-sim.ts` internals (private
  fields, non-exported helpers) that would break once those internals move modules — grep for
  imports from `test/simulation/fret-sim.js` across the whole test directory first.
