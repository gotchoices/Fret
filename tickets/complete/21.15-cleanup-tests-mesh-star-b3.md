## What the implementation did

`peer-discovery.spec.ts`'s three-node setup — three `createMemNode()`s, a `FretService` on each,
and a star dial at node 0 — was replaced by the shared `helpers/mesh.ts` rig
(`buildMesh` → `addServices` → `connect('star')`).

## What the review added

`starMesh(count, opts?)` in `helpers/mesh.ts`, and four specs migrated onto it. It is the
`buildMesh` → `addServices({profile:'edge', k:7, bootstraps: i===0?[]:[ids[0]]})` →
`connect('star')` sequence in one call, with an optional `config` merged over the defaults.
`buildMesh` plus the two calls stays the path for any spec whose ordering or config differs; the
`starMesh` doc block says so, so the module header's "two calls on purpose" rationale is preserved
rather than contradicted.
