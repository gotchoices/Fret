## Already applied — do not redo

- **The fourth case was vacuous and is now rewritten.** It read "a route whose originator is
  already the peer nearest the target still succeeds" and completed all 20 of its routes at hop 0,
  never calling the selector — deleting the `hops > 0` split at `test/simulation/fret-sim.ts:887`
  left it passing 20/20. Root cause: `handleRoute`'s anchor check
  (`test/simulation/fret-sim.ts:844-850`) runs before any hop is chosen, and a peer that is
  locally nearest a coordinate *is* that coordinate's successor or predecessor in its own store,
  so locally-nearest implies hop-0 termination. Nor can any rewrite reach the split through a
  route: if the originator is *not* the anchor, its store's successor and predecessor of the
  target are both in the candidate pool and at least one is strictly closer, so the floor cannot
  bite at hop 0 either — unless every nearer entry is `dead` (the pool is `notDead`-filtered while
  the anchor check deliberately is not), which is a partition-shaped case, not a routing one.
  The case is now `an originator already nearest the key has no strictly-improving first hop` and
  calls `chooseNextHop` directly, asserting that supplying `selfCoord` strands the originator
  (returns `undefined`) while withholding it yields a hop.
- **Both documentation statements are corrected** — the spec header comment and the *Testing
  strategy* bullet in `docs/fret.md` (~line 842). Neither now claims the case pins the
  from-hop-2 floor; both state that the sim's split is unobservable through any route here.
- **The DRY question is decided and applied.** `toCoord` / `refMinDistance` live in
  `test/helpers/ring.ts`; the routing spec's case selection stays on that reference arithmetic
  rather than `src/ring/distance.ts`, so choosing the case is a cross-check on the selector
  rather than an assumption about it.
- **`report()`'s `console.log` stays.** Sibling simulation specs (`churn-scenarios.spec.ts`,
  `sim-profiles.spec.ts`) print their measurements the same way.
- **Verified green:** `npx tsc --noEmit` clean; `test/simulation.routing.spec.ts` 4 passing
