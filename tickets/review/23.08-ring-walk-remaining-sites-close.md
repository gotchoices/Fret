## Confirmed finding — fix it

**`SizeEstimateOptions.selfCoord` and `selfId` are two independent optional fields that are only
meaningful as a pair.** `collectGaps` passes `selfId ?? ''`; an empty string matches no peer id,
so the helper's `drop` predicate never fires, each side spends a slot on the anchor entry, and the
window silently loses one gap per side — G = 2m − 2 = 14 at the default m instead of 16
(confidence 0.8664 rather than 0.875). Quiet numeric degradation, not an error, and
`SizeEstimateOptions` is exported from the package root (`src/index.ts:142`), so an external
caller can reach the half-specified state.

Architecture ladder rung 1 (types/representation): pair them so the half-specified anchor is
unrepresentable and the `?? ''` fallback retires with it.

```ts
export interface SizeEstimateOptions {
	filter?: (e: PeerEntry) => boolean;
	/** Local node's ring position *and* id. Supplying it selects the S/P-window method. */
	self?: { coord: Uint8Array; id: string };
}
```
