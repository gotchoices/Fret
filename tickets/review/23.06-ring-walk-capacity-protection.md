  `+1, +2, +1000 … +6000, -2, -1`, so with m 3 the protected set is self, `near-cw-1`, `near-cw-2`,

  against a cap of 8 evicts the three lowest-scoring *unprotected* entries, `far-2` … `far-4`.
  Asserted survivors match.
- *protects the m-th successor and m-th predecessor* — protected set is self + `succ-1..3` +
  `pred-1..3` = 7; the three evictions are `far-1` … `far-3`, leaving `far-4`. Matches.
- *protects self when the ring walk returns nothing* — every other peer is `foreign`, so the
  filtered walk matches only self, which is excluded by id, so it returns empty. Protection is
  `{self}` alone and the three foreign peers are evicted down to the cap of 1. Matches.

The load-bearing claim (protected = self + `max(2, m)` nearest live members clockwise + the same
counter-clockwise, window skipping past non-live-members rather than shrinking) therefore holds at
the three fixtures that test it most directly.
