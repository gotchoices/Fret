## Diff review — already done, do not redo

The split (commits `e542e9c` new modules, `d48ce8a` rewire) is a faithful move of code out of
`test/simulation/fret-sim.ts` (1050 → 779 lines) into four modules. Every extracted doc comment
survives verbatim; the remaining public methods on `FretSimulation` (`partition`, `heal`,
`crossPartitionBlocked`, `snapshotCoverage`, `deadNeighborRatio`) are one-line delegates.

Checked and clean:

- **`uniformCoord` de-duplication is safe.** The old inline byte loop was replaced with
  `helpers/ring.js`'s `toCoord`. Read both: same big-endian layout, same 32-byte width
  (`COORD_BYTES`), and `toCoord`'s extra mod-2^256 reduction cannot change a value the old loop
  produced, since it only ever received in-range products. Byte-identical.
- **Same-seed determinism preserved.** `CoordPlacement` is constructed immediately after the
  message bus, which consumes no RNG, so clustered mode's cluster-centre draws happen at the same
  RNG position as before the split. This is the one constraint a future reordering of constructor
  lines would silently break; it is already called out in a comment at the site.
- **No duplicated partition state.** `LivenessModel` sees reachability only through the injected
  `contactAllowed` predicate. `PartitionModel`'s `hasPeer` thunk is exactly the old
  `this.peers.has(id)`.
- **Held map references are sound.** `SimMeasurement` captures `peers` and `stores` at
  construction; both are `readonly` fields on `FretSimulation` initialised once and only ever
  mutated in place, so the captured references never go stale.
- **No import cycle.** `measurement.ts` declares its own structural `MeasurablePeer` rather than
  importing `SimPeer` back from the composer, and the `Map<string, SimPeer>` →
  `ReadonlyMap<string, MeasurablePeer>` narrowing needs no cast (covariant reads).
- **Re-export surface is complete.** `PlacementStrategy` / `ClusterConfig` are re-exported from
  `fret-sim.ts`, so none of the six spec files importing from it needed an import-path change.

No findings worth fixing were surfaced by the read. No new tickets warranted.
