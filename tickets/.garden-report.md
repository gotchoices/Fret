### What shipped

`registerRpcHandler` now builds its `node.handle` options through a private `handleOptions()`:

```ts
function handleOptions(caps: StreamCaps): StreamHandlerOptions {
	const options: StreamHandlerOptions = { runOnLimitedConnection: true };
	if (caps.maxInboundStreams !== undefined) options.maxInboundStreams = caps.maxInboundStreams;
	if (caps.maxOutboundStreams !== undefined) options.maxOutboundStreams = caps.maxOutboundStreams;
	return options;
}
```

Two defects at one site: the missing relay opt-in on the *answering* side (the dialing side in
`openRpcStream` was already correct), and the two cap keys being passed as `undefined`, which
spread over libp2p's registrar defaults and replaced 32/64 with no cap — dormant for FRET's own
registrations, live for outside callers of the exported seam.

### The triage commit is the one to know about

`9512f0f` is **not** part of the relay ticket. The implement agent hit a pre-existing
`message-bus` clustered-placement timeout, filed `.pre-existing-error.md` per the rules, and the
runner's triage pass fixed the root cause: `DigitreeStore`'s `byId` map now holds the **entry
object** rather than its tree key (so `getById` is a map read instead of a full tree descent), and
the `makeKey` cache is re-keyed from entry-object identity onto the **coordinate array's**
identity, guarded by the entry id.

That is a real hot-path change, so it was gated separately. The reasoning recorded at the site is
measured, not asserted: every write path hands `put` a freshly-spread entry, so an entry-keyed
cache was a guaranteed miss on every write and left a dead weak-table record behind each time —
measured on the 300-peer bounded-store simulation (3.4M writes, 66M extractor calls) at 25–35 s
entry-keyed, 9 s with no cache at all, 3.3–4.3 s coordinate-keyed. An entry-keyed cache was several
times *worse* than none. The store invariant is unchanged in substance and all four `byId` sites
(`put`, `remove`, `getById`, `size`) agree; `test/digitree.invariants.spec.ts` is the model-based
property test that covers it.
